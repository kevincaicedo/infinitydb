The tape

A document is stored as an idoc tape: one-byte tags, small integers and short strings inline, 64-bit integers and doubles, and objects and arrays with a 24-bit length, so any subtree can be skipped in one step. Each value has exactly one encoding and the validator rejects any other, so two equal documents are byte-identical. That lets replay and tests compare raw bytes.

A document of up to 512 bytes lives inside its record; a larger one lives in the cell's document arena and the record points to it. Nesting is capped at 128 containers and a document body at 16,777,192 bytes, so every document fits one record and one full-image log record. A write whose result would cross either bound is refused before anything changes, for example with ERR document nesting too deep.

The parser follows simdjson: SIMD classification of 64-byte blocks, then one streaming pass that writes the canonical tape directly, with no intermediate tree.

Where the corpus finds a difference, the matrix says so. A few deviations are product boundaries: InfinityDB refuses a write that would nest past 128 containers, where RedisJSON stores a document it cannot read back; JSON.ARRINSERT validates every match before it changes any, where RedisJSON can mutate an earlier match before a later index error; type errors use the core Redis WRONGTYPE text. JSON.MGET is atomic per key, with no snapshot across cells. JSON.RESP is deprecated upstream and will not be added.

JSONPath and reply shapes

Paths use the JSONPath subset: $, .name and ['name'], .* and [*], indices including negatives, Python-style slices such as [::-1], unions of 2 to 16 selectors, and recursive descent with ... A path that does not start with $ is a legacy path with an implicit root, as in RedisJSON. Path text is bounded (4 KiB by default, at most 128 segments).

Each path compiles once to a small bytecode program, cached per cell in a bounded LRU (doc-path-cache-size, 1,024 entries by default, 0 to 4,096, set at boot with --doc-path-cache-size). The compiled bytes are the program, so the same bytes are cached and written to the log.

The mode decides the reply. A $ path answers the whole match set, as JSON text holding an array: "[4499]" above. A legacy path answers one value: the first match for reads, the last applied match for writes. The generated reply-shape table lists every command in both modes and both protocols. Serialization runs against a reply budget, 128 MiB by default, and answers ERR reply too large beyond it, because $..* or repeated paths can make a reply far larger than its document.

Path updates and durability

A path write changes only what the path selects; the client never re-sends the document. The mutation is planned against the whole match set first: every edit is validated (types, integer range, the size of the result) before any output exists. Then one pass writes the new tape. There is no rollback path, because nothing partial is ever built. Integers stay exact 64-bit values, and an overflow fails the whole command.

On a durable namespace a write is logged as a small delta, the path program and the operation, instead of the whole document. After 64 deltas, or once the deltas since the last full image add up to the document's own size, the next write logs a full image, which bounds how much replay must apply to rebuild any document. A lineage number ties each delta to one incarnation of the key, so a delta can never apply to a document that was deleted and recreated in between. Replay applies the same pure function of document, program and operation.

Document memory is attributed per document. JSON.DEBUG MEMORY key reports the record and external document bytes charged to that key; shared pools and allocator slack stay in INFO memory, under the used_memory_doc_* fields. See Memory & eviction.

Not yet

Not yet

JSONPath filter expressions (?(@…)) are refused today with a typed error. They arrive with secondary indexes and queries, later in M4. Documents beyond RAM, with expiry and indexes on tiered namespaces, are the last phase of M4: a tiered namespace refuses JSON.* today.

The document engine is feature-gated. Building the inf-server library without default features leaves out all document and path code, and the JSON.* rows answer unknown-command; CI checks that build's symbols. The infinityd binary always includes the document engine for now.

L9
Safety is layered.

Every document byte is untrusted until a decoder has checked it. The JSON parser, the path compiler and the tape validator are iterative, bounded and total, with no recursion. Each of them, and delta replay, has a fuzz target in the nightly campaign.
